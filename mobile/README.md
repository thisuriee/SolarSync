# Mobile Client — Setup Instructions

> **Placeholder note:** this folder does not yet contain an Android project. The
> project must be created by a student through the Android Studio new-project
> wizard, not generated by a tool. Delete this note once the project exists.

## 1. Create the project in Android Studio

Use **File → New → New Project** and choose:

| Setting | Value |
| --- | --- |
| Template | Empty Views Activity |
| Language | Java |
| Package name | `com.sliit.smartsolar` |
| Minimum SDK | API 24 |
| Build configuration language | Groovy or Kotlin DSL (agree as a group first) |

Set the project location to this `mobile/` folder so the Android project sits
alongside `api/` and `web/` in the same repository.

## 2. Remove the placeholder note

Once the project has been created and opens successfully, delete the placeholder
note at the top of this file and keep the rest as onboarding documentation.

## 3. Create the package folders by hand

Under `app/src/main/java/com/sliit/smartsolar/`, create these packages:

- `activities`
- `network`
- `database`
- `models`
- `parsers`
- `utils`

Create them in Android Studio via **right-click the package → New → Package** so
the folder and package name stay in sync.

## 4. Add local configuration

Add the following entries to `local.properties`. This file is gitignored and
must never be committed — each member keeps their own copy.

- `API_BASE_URL`
- `MAPS_API_KEY`

Ask the group for the current values; do not hard-code them into source files.

## 5. Networking constraints

This client is **pure native Android**. Networking is done with
`HttpURLConnection` and JSON is handled with `org.json` only.

Do not add Retrofit, OkHttp, Volley, Gson, Moshi, or any cross-platform
framework. Adding one breaks the project constraints.

## 6. PATCH requests

The hosting environment does not reliably pass through the `PATCH` verb, so any
PATCH operation is sent as a `POST` carrying the header:

```
X-HTTP-Method-Override: PATCH
```

Apply this consistently wherever the API contract specifies PATCH.
